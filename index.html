Import / Export / Templates

Workflow: teams fill the template → you Import once → review merge → Export JSON → save as data/ideas.json → commit to Git. The portal always reads the committed JSON on open.

1. Templates (for teams)

Give teams this one workbook. They fill the Ideas & Metrics tabs (Progress Log optional) and send it back.

2. Import (you)

Import a team file (.xlsx/.csv) or a full backup (.json). Imports merge by ID/Title — you'll see a preview before applying.

3. Export & Save (you)

Export the master, then commit data/ideas.json to Git so everyone sees the update.
